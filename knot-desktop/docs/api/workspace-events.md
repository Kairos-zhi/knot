# 工作站变化通知

030已独立限定接受，详见[任务卡](../tasks/KONT-WORKSTATION-030.md)。复用已有认证SSE GET /kont/events?since=seq。服务事件不变，客户端只用它判断已知快照可能过时，不把事件正文合入资产或用来确认命令执行。

事件序号属于整个workspace；其他现场或运行记录的变化也可能要求本页核对。客户端不按事件正文筛选当前现场，避免把全局版本变化误当作无关通知。

工作站挂载且持有已接纳快照时保持一条同源EventSource。workspace请求开始关闭旧流；成功接纳新快照后按其seq重建。这样不靠事件source猜测自己的写入。订阅间隙由服务backlog补告知；缓存不足或服务冷启返回reset。读取与订阅不原子，最终陈旧写保护仍由revision检查负责。

更高序号的通知、reset或监听失败都会关闭监听、清除过期预览和运行产物视图，保留已知快照与本页草稿，要求手动刷新并阻止提交。旧或重复普通通知不触发动作。只读必要序号和reset标记，后台正文不进入用户提示。坏格式、缺能力或构造失败同样显示固定失败信息。

断线立即close，禁止原生自动重连被误当作恢复。用户刷新失败继续保持屏障；成功读取后重新订阅，不自动保存、重放或另发workspace读取。组件卸载和插件dispose都会关闭并失效旧回调；未挂载时不会因迟到响应重新开流。重新挂载若已有错误，仍需手动刷新。

仅当前挂载工作站监听，草稿保护仍在当前provider内存。不提供后台全局同步、跨重启草稿恢复、完整命令幂等或绝对实时一致。隔离HTTP SSE契约和程序化EventSource回调测试不证明实际dsh-app长流能力、浏览器布局或人的体验，当前未更新在用桌面。
