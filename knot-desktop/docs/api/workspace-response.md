# 工作站响应接纳

029已独立限定接受，详见[任务卡](../tasks/KONT-WORKSTATION-029.md)。在028的HTTP/网络/解析错误恢复之外，工作站还必须确认成功JSON足以安全读取，再改变已知快照或清理本页草稿。

接纳只检查当前界面和产物定位读取的字段与身份：revision/seq为非负安全整数、现场数组与活动现场、各现场草稿/材料标识数组/标题、材料标题摘要及可选块的身份和正文、呈现条目的身份与必要属性。同类身份不能重复。已知revision/seq不能回退；允许相等，不要求两者相等。

材料blocks可以缺省；若存在则须为数组，块只要求有效身份和字符串正文，不强制来源或时间戳。呈现kind为现有window/card/icon、closed为布尔值，不要求layout。检查不修改标识或正文。

这是客户端接纳检查，不替代store完整校验或权限判断。不检查完整Run journal/边/来源元数据，不填默认值、不规范化、不裁掉未知字段，也不从坏数据拼出一个可用现场。合法响应保留原有内容和额外字段。

写入成功响应还须回显本次发送的现场草稿：原现场存在，文本与捕获的提交值相同，才可以按026既有规则清理dirty；保存期间追加的本地文本继续保留。缺失或不符时全部视为结果待核对，不部分清草稿。读取允许其他窗口的合法新内容，仍保留本页dirty。

拒绝时沿用[028恢复](workspace-recovery.md)：保留最后已知快照、本页草稿和离页保护，显示固定提示并阻止继续写入，等待手动刷新；不自动重试或回放命令。草稿回显不证明其他命令的全部效果，也不构成未知历史命令的幂等回执。

当前仅源码/build/程序化组件语义，未更新在用桌面，也不代表浏览器、正式Apple工作站或人的体验接受。
