# DSH 单会话读取与请求边界既查

本卡为KONT-RUN-005，基线7f7bc42，2026-10-22。只读官方0.2.1-rc.2 ASAR源码，不读用户Session、Provider配置或凭据；源成员路径/SHA见本轮research/manifest.json。复用已限定接受的RUN-004身份与固定输入，原冻结清单不改。

| 发现 | 取舍 |
|---|---|
| sessionQuery.readSession冷读先list全库，readColdSessionLog补interruptedTurnClosers | 不作为原始持久证据入口，避免全库内容发现与虚构终态 |
| observeSession使用prepared lease，并可能经projection计算；follow还有promote行为 | 本卡不使用它们激活或恢复Agent |
| persistence.stat(id)可提供formatStatus/revision；open(id,'read')不拿写句柄，read/close可单目标读取 | 先许可→stat current→read handle→close→确认revision稳定；拒绝historical migration/seeded。下层后端有目录定位，不声称物理I/O零元数据扫描 |
| JSONL只读旧格式可内存迁移且header转current | 仅检查handle.header.version不足，先stat.formatStatus；只采用current v4窄范围 |
| Persistence契约不向read句柄返回撕裂的物理尾，只交有效连续逻辑前缀 | 点读是逻辑日志观察，不是原始文件字节取证；revision稳定不证明不存在被后端隐藏的物理残尾 |
| Session.create重放验证runtime-required字段/seq/surface，另补session/end-seed内存标记 | 使用官方重放语义，不将补标记当持久事件，也不称完整schema校验 |
| 实际JSONL读回会规范化header并补delegationDepth:0 | 重放和指纹以持久句柄/稳定stat的规范化header为准；不将创建时内存header与规范化header误当同字节 |
| agent-loop.buildRequest先记录header/context，再deriveMessages构造header.config＋messages＋toolHistory＋tools | 本卡对首turn/单step/一次assistant/纯文本无工具，在assistant前缀重建相同请求边界；Provider转换后HTTP、全插件语义未验证 |
| request/context含provider/model、contextWindow、可选systemPromptUpdate；header包含config/adapterDefaults/tools | 模型route和有效header/context/messages、permission事实进入审计指纹，不能只核用户prompt |

完整上下文在此指**该窄请求边界的DSH派生消息集合**，不是“模型最终看到了所有内容”的运行证明。system/developer输入必须影响指纹；核准读某Session不自动核准请求指纹或执行，任何结果executionAuthorized=false。hash是完整性关联，不提供外部来源签名或安全保证。

bounded read限制返回事件数；后端仍可能解析完整physical artifact。本卡可用stat字节数和返回内容字节上限拒绝超量，但不宣称严格流式内存界限或压缩炸弹防护。官方schema检查也不验证所有Provider stream；合成fixture的空stream不能当真实流一致性证据。

真实性边界来自宿主注入的实际服务能力与服务侧单Run绑定；不能接受普通HTTP提交“trusted:true”或文件路径。缺少许可即不访问底层服务；缺少请求指纹核准不产生ready。重建内容不进入资产或日志，只保留必要指纹和脱敏元数据。

实际验证使用官方安装Electron RunAsNode，仅加载Session／JSONL持久化相关库，在D盘独立fixture root中由官方库创建合成Session后点读／重放。它证明真实官方库接缝执行，模型／Agent运行仍为0；不能将该测试称实际模型Run或桌面部署。

竞对采用依据仍为冻结研究O4/O5/O8/F4：对象/Session身份分离，准确来源与输入检查，恢复/取消事实独立；不复制竞品代码。前端不改，Apple基准保持。未查询远端治理表，未重新读取8份私有飞书原文，不宣称全域既查。
