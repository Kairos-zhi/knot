## 定案背景（必读）

knot 的操作语言只有三样工具（之定）：
- **棍子**（对象/结/资产：不同形式的资产，可以是对话线性流本身）
- **绳子**（连接：串链/织网/拴项目；打结=固定）
- **剪刀**（断开：剪断绳/剪开结）

对应思考三动作：拿起想法 / 连接想法 / 拆开想法。工具范式=显式三件套，光标即工具，一切操作归入棍/绳/剪。绳是核心：串的顺序=思考路径（第二弹模式 2 路径痕迹）。

## 一、工具条（三件套）

- 底部中央工具条：棍子/绳子/剪刀 三按钮，当前工具橙色高亮（#ff9500）
- 快捷键：1=棍子 2=绳子 3=剪刀
- 切换轻量（无大动画）；工具条样式克制（与画布融合，半透明底）

## 二、棍子（Stick）——默认工具

**现有行为全部保留**（选择/焦点/展开折叠/续长/勾选/移动），不需要新逻辑，只需确认默认工具=棍子。

## 三、绳子（Rope）——核心新工具

### 串（thread）：拖绳穿珠成链
1. 绳子模式下，从结 A 按住拖出（不移动结，拖出的是绳头）
2. 绳头经过结 B/C → 松手在 C 上 → 按经过顺序建绳 A→B→C（edges 按序创建：A→B、B→C，sourcePortID 'out' / targetPortID 'in'）
3. 拖出过程中：虚线预览绳（跟随鼠标），经过的结短暂高亮（吸附标记）
4. 顺序即路径：A→B→C 是思考路径，不是无向连接

### 吸附成绳（第二弹模式 8 直觉入口）
1. 绳子模式下拖结 A 靠近结 B（距离 < 120px）→ B 出现光晕（.knot-node--attract）+ 虚线预览绳
2. 松手 → A→B 成绳（不兼容的结不发光、无报错——错误沉默原则）

### 打结（固定）
1. 绳头拖到目标结上停留 ≥300ms → 打结固定：绳上出现小结节（视觉：比端口大的圆点，色 #ff9500 或灰，位置在绳与结的接触点附近）
2. 解结：绳头再拖开（或右键小结节→解除）
3. v1 打结=视觉+语义标记（绳的 fixed 属性），不做复杂锚点

### 拴（跨域）——后置
v1 只做域内（语义空间内/线性流内）串绳；跨项目拴接后置（需要多项目数据）。

## 四、剪刀（Scissors）——断开工具

1. 剪刀模式下点一条绳 → 剪断：该绳从中间断开，两端独立（下游链保留）
2. 剪刀模式下点一个结 → 解开：该结所有绳解除（结保留在画布，成为孤立点）
3. 剪断反馈：断点闪一下（浅灰），不弹窗无报错
4. hover 绳 → 绳高亮（可剪提示）；hover 结 → 轻微提示（可解开）

## 五、数据与持久化

- 绳=现有 edges（KnotEdge 结构不变）；剪断=删除该 edge；串=按序创建 edges；打结=edge 加标记（data.fixed=true，写入 edge.data）
- 双向同步：所有绳操作（串/剪/结）触发 document 变更 → 写回资产文件（现有 watchCanvas 链路自动覆盖）
- 线性流联动：语义空间里串的链，切到线性流视图应能看到对应顺序（v1 最小：线性流按 chain_id 显示；绳串的新链（chain_gen 或其他）在流上出现）
