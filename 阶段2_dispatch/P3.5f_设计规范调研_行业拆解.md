# K3 调研委托：knot 设计规范 v1（行业规范拆解）

## 任务
调研行业已拆解过的设计规范，产出 **knot 设计规范 v1**——按钮摆放、边缘距离、形态关系、卡片生成规律，全部给到可直接落地的规格数值。

## 调研对象（联网/已有知识，优先权威规范原文）
1. **Apple HIG**：窗口与组件规范（红绿灯尺寸与间距、工具栏、按钮尺寸 44pt 触控目标、内容边距）
2. **Material Design 3**：栅格系统（8pt）、间距阶梯（4/8/12/16/24/32/48）、圆角阶梯（4/8/12/16/28）、状态层、形状规范
3. **卡片类产品的组件拆解**（Notion / Linear / Figma / Craft 等）：卡片内部结构（标题区/内容区/操作区）、操作按钮摆放位置规律、卡片间间距、hover/focus 状态规范
4. 已有 knot 视觉语言（读代码感知）：克制风、单强调色 #ff9500、毛玻璃、低对比、疏离感（规格 v1 定案）

## 产出（写入 C:/Users/x2270/hermes-sync/kairos-oracle/knot设计规范_v1.md）
一、**设计 tokens**：间距阶梯/圆角阶梯/阴影/描边/字号阶梯/色彩（可直接写 CSS 变量）
二、**卡片组件规范**：
   - 卡片尺寸（折叠态/展开态宽高）、内部结构分区（灯区/标题区/内容区/操作区）、内边距
   - 按钮摆放：红绿灯位置与间距、绳孔位置、展开按钮位置、勾选框位置（每个给具体数值：距边缘 px）
   - 卡片间间距（画布上结与结的最小间距）、hover/focus/active 状态规范
三、**形态关系**：
   - 卡片折叠↔展开的过渡规范（尺寸变化/内容进出/时长）
   - 卡片与链卡、工具条、线性流面板的层级与间距关系
   - 绳子/徽章/光晕的视觉参数（线宽/圆点大小/徽章尺寸）
四、**生成规律**：
   - 新卡片的初始位置规律（从来源结的哪个方向、偏移多少）
   - 画布初始布局规律（分组间距、行列距）
   - 卡片尺寸随内容长度变化的规律（最小/最大、截断）
五、**应用优先级清单**：当前实现里与规范不符的 top 10 项（列出文件+改法）

## 约束
- 规范要有数值（px/pt），不写模糊的"适当""合适"
- 遵守 knot 视觉语言：克制、单色 #ff9500、疏离、低信息密度
- 报告写文件，完成后报文件路径+核心 tokens 摘要
