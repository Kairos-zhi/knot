## 三轮真实工作

预置 I1–I4、K-01 和 N1，冻结材料版本；后续 K-02–K-04 由真实运行产生。

| 轮次 | 操作 | 必须核对 |
|---|---|---|
| 初始 | 仅查看 K-01／N1 | 输入为空，未因预览授权 |
| R1 | I1/I2/I3，分别交 Codex 和 Hermes | 同 Focus／dialogue 下两个独立 runId；来源分别保留，指定一份结果为 K-02 |
| R2 | 增 I4，Codex 继续 | 实际输入恰为 I1/I2/I3/I4；原对话连续，产物 K-03 |
| R3 | 排除 I2，选 K-02，Hermes 继续 | 实际输入恰为 I1/I3/I4/K-02；不递归重新读取 I2，产物 K-04 |

N1 从不选择，实际请求与工具轨迹不得泄漏。检查 I2 历史泄漏时用未出现在 K-02 中的专属标记。K-02 自身包含的文字属于主动选入内容，不把它误报为越界。K-03／K-04 不自动成为后续输入。

## 运行、恢复与副作用

| 故障／动作 | 必须证明 |
|---|---|
| 停止／失败 | 准确区分终态，不生成伪成功正式资产 |
| 收起／关闭呈现 | 不改变对象身份，不隐含取消已托管任务 |
| 页面关闭／宿主中断 | 可回收运行，或明确失联与恢复入口 |
| 事件重复／断线 | 不重复创建正式产物，缺口按 snapshot 对账 |
| 派发回执丢失 | 先确认是否已接受，再决定可否重试 |
| 恢复／回滚失败 | 保留最后有效字节，隔离不完整状态，显式修复 |
| 自动整理与人工修改冲突 | 固定、排除、隔离不被悄悄覆盖 |
| 同对象多个呈现 | 不产生平行内容，版本冲突有明确结果 |
| 新来源／工具读取 | 范围符合授权，错误／覆盖度可见，不用输入选择冒充沙箱 |

后续原生阶段另测跨屏、缩放、输入焦点、捕捉拒绝、休眠重连；Jev 试点另测过期 revision、输入中／固定守卫、超时与降级。

## 证据格式与独立性

每次记录基线／差异、环境、实际命令和退出码、输入与产物哈希、Run／Session／turn／事件关联、结果位置、失败及未覆盖项。流式展示与最终产物分别记录；token 估计和实际 usage 分栏。

Maker 可自测并交候选；Checker 未参与同一候选制作，给直接结论。用户的产品取舍与体验判断单列。合并、文件存在、静态图像和命令零退出都不替代完整范围的验收。

工程遵循服务层→程序化→人类过手阶梯，不以截图／模拟点击验证原生操作能力。人的真实体验反馈有价值，与自动截图点击测试是不同用途。
