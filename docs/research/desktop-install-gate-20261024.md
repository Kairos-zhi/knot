批准接口接收可信调用者对明确用户许可的声明，绑定精确descriptor摘要／目标／有效期；这只是调用方的授权声明记录，不是签名或真人身份认证。声明只留hash。合成与真实声明类型在私有grant中区分，生产transport不接受synthetic；测试使用隔离模块根及独立ledger分区，不污染生产一次性占位。

稳定descriptor不含随机计划ID、签发时间与expiry，因此同目标／候选／数据不能靠重建计划绕开占位。唯一dispatch前先wx写入reserved并sync，任何失败都保留占位，不删除或自动重试。超时不代表远端取消，返回不确定并保留晚完成风险；manager的restart-required仅是安装结果，不是active加载或完整部署接受。正常重开与系统断电保证分开，不能声称exactly-once。

超时边界具体为：尚未消费的permit失效，不能随后才开始派发；已消费permit而进入transport的操作可能继续本地准备甚至之后才调用manager。执行器超时返回不确定后，晚结果不改写为submitted，也不能据此声称profile一定没有变化；需要等待／诊断已有操作，不能再次执行或强制清除占位。

除持久claim外，执行器在占位后签发私有单次dispatchPermit；transport消费它，核持久claim，再独占transport marker，以免直接callback绕过“保留reserved、不重试”的规则。调用前再做来源／数据校验，篡改／过期／未发permit／重复消费在真正manager前拒绝。
