|---|---|---|
| 1 | [交互实现](archive/interaction.md) | 窗口语义、焦点、动效与直接操作；旧红绿灯不包办新生命期 |
| 2 | [设计系统](archive/design-system.md) | 字体、色彩、材质、图标、声音、动效维度；具体参数待承载验证 |
