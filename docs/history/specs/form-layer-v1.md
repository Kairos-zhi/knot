# knot 形式层设计规格 v1

> 2026-08-29 晚 · 依据：深度调研报告（游戏行业 11 案例 + 字节语义空间 + 13 条交互模式）→ 本规格

### 后置（7 条，不阻塞 v1）

- 连接即重叠（拖拽吸附提示）——交互成本中，v1 后
- 验证即牢固（多源交叉验证标签）——社区尺度的事
- 路径=痕迹（浏览轨迹可视化）——成本高，等社区数据
- 嵌套网络（多层结共存）——等结型深化
- 决策分支显式化（A/B/C+D 平行宇宙）——M1 对谈实验后，杜方案已立
- 时间轴=进度条（电影式回溯）——等时间轴功能线
- 结的生长态（模糊→清晰渐进）——等结型 v2（**8/30 机制背书**：打结=Cola 逐块推进，非一次性；v1 可先支持「结追加/续长」）

## 三、焦点定义（待拍项草案）

**推荐方案：焦点 = 当前激活的结（选中即焦点）**，两种来源：
1. 用户主动点选一个结 → 该结成为焦点，界面围绕它重排（星际拓荒橙色星号模型）
2. 用户正在对话（勾选=上下文注入时）→ 被勾选的结自动成为临时焦点，对话结束焦点保留

不采用「当前对话流自动焦点」——太飘，用户会不知道焦点在哪。**焦点必须可见、可移动、可清除**。

**勾选粒度（8/30 机制背书）**：勾选=定义可见集 V_b，合法粒度=结内块~语义邻域；v1 先支持「按结勾选」，块级粒度后置。

## 四、视觉语言（与审美对齐）

- **远近即权重，用「疏密+虚实」表达，不堆色**：焦点区密实清晰，边缘稀疏虚化——天然留白，符合疏离/克制/低密度
- 焦点标记只用一种强调色（单色星标/亮度差），不引入多色系统
- 聚合节点用主题色点（沿用 011g 现有主题色体系）
- 「?」空位用虚线轮廓，视觉上「未完成但不吵」

## 五、验收标准

v1 完成后，打开画布一眼能回答三个问题：
1. **焦点在哪**（第一个看到的）
2. **什么离我近**（当前相关，清晰）
3. **哪里还有空白**（? 位可见，有引力）

外加：频繁引用的结「看起来更实」，冷落的结「淡而不消失」。

## 六、机制背书（2026-08-30 · Cola 操作序列同构）

knot 操作流 = Cola 推理循环的外化（打结=编码 / 勾选=可见集 / 生成=解码+追加），四则设计决策：

1. **结支持生长态**——打结=逐块推进，结可续长（对应后置 #7，v1 可先支持「结追加/续长」）
2. **勾选粒度对齐块**——结内块~语义邻域都是合法 V_b（v1=按结勾选，块级后置）
3. **生成自动成结**——解码即打结，生成内容免手动收尾（FlowGram 阶段 2 勾选注入的生成链路按此设计）
4. **摘要必须可展开**——压缩可解码，摘要=压缩表示非丢信息，摘要视图必须可一键展开回原文

## 八、红队修正与阶段 3 优先级（2026-08-30 · K3 深度推理红队 + 之拍板）

**两处硬伤定案（红队建议全收）：**
1. **权重分层**：位置布局权归焦点距离（#1 独占坐标），使用计数只调制视觉通道（透明度/实感，#6 不碰位置）——「位置看焦点，虚实看频次」
2. **位置惯性**：清除焦点后布局冻结不动（只去星标），下一个焦点出现才重排；单击空白不清除焦点（误触保护），双击/长按才清；ESC=取消当前操作流

**三坑闭环建议（v1 内落实）：**
- 摘要级勾选：被勾选结超 token 阈值（>X）强制摘要注入（背书④摘要可展开正好复用）；生成结记录 provenance（由哪些 V_b 生成）
- 生成两阶段提交：生成中=画布临时对象（t- 前缀，不写盘）→ 完成=分配正式资产 id 原子写回；失败/取消=临时进回收站；写回 append-only 块日志
- 去重靠 provenance（同 V_b+同 prompt 重复生成提示，不自动合并）

**阶段 3 优先级（红队排序：先修地基→同构主干→氛围层）：**
- P0 块数据模型+生长态（结=有序块序列 [手写/生成, 时间戳, provenance]；追加=尾部增块，续长=以该结为 V_b 生成接尾；块模型=生成链路/块级勾选/写回去重公共地基，最高杠杆）
- P1 焦点物理重排+权重分层规则（位置惯性落地）
- P2 生成两阶段提交（接真实 LLM 前必修）
- P3 使用即加固（计数白名单：勾选+3/被引用+2/展开+1/焦点+1；半衰期 7 天；三桶视觉；淡化地板 alpha≥0.25）
- P4 聚合=语义簇（密度触发 L1 显式主题簇/L2 兜底簇，禁 L3 LLM 聚类；焦点结所在簇永不聚合）
- P5 ? 位兑现（点击即打结进入编辑态）
- **UI 美化后置**（之拍板：v1 跑通地基优先）
