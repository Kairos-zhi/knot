# knot 设计规范 v1

> 依据：Apple HIG（窗口组件/44pt 触控目标/工具栏）、Material Design 3（8pt 栅格/间距阶梯/形状阶梯/motion）、卡片产品拆解（Notion/Linear/Figma 的卡片四区结构）
> 遵守 knot 视觉语言（规格 v1）：疏离/克制/低信息密度/单强调色 #ff9500/毛玻璃/错误沉默
> 2026-08-30 · 中控产出（K3 调研后落盘）

## 二、卡片组件规范

### 尺寸
| 状态 | 宽 | 高 | 说明 |
|---|---|---|---|
| 折叠态 | 自动（min 140px，max 240px） | 44px（HIG 触控目标） | 一行：灯+标题+▸ |
| 展开态 | 240px 固定 | 自动（min 120px，max 视口 70%） | 内容区可滚动 |

### 内部四区（从上到下）
1. **灯区**：高 16px；三灯 11px 直径，间距 4px（gap）；距卡片左缘 10px、顶缘 8px
2. **标题区**：标题 13px/500；距左缘 10px；下方与内容区距 8px
3. **内容区**（展开态）：块列表，块间细分隔线（#f0f0f0 1px）；块内文 12px/1.5；上下 padding 8px
4. **操作区**（展开态底部）：续长按钮虚线框，高 28px，距卡片边缘 10px

### 按钮摆放（距边缘数值）

| 状态 | 边框 | 灯 | 透明度 | 动效 |
|---|---|---|---|---|

## 三、形态关系

### 卡片 ↔ 卡片
- 最小间距 32px（防重叠）；同链相邻 24px；不同链组间 48px
- 展开卡片压盖其他卡片（z 层级见七）

### 卡片折叠 ↔ 展开过渡
- 时长 350ms，--knot-ease-out；尺寸变化 + 内容淡入（opacity 0→1，200ms 延迟）
- 展开时其他卡片毛玻璃化（far：blur 2px + opacity 0.4）——不动位置（位置惯性）

### 卡片 ↔ 链卡
- 链卡固定右下角（距右 24px、距底 108px——工具条之上）；宽 280px
- 链卡出现动画 350ms（从右下滑入 + fade）；关闭=绳保留

### 绳/徽章/光晕视觉参数
| 元素 | 参数 |
|---|---|
| 绳线 | 1px，色 #b8b8b8；hover 2.2px #ff9500；选中 1.6px #ff9500 |
| 绳头橙点 | r=5px，色 #ff9500；呼吸光晕 r=11px stroke 1.5px halo 0.4 |
| 序号徽章 | 圆 r=11px，底 #ff9500 白描边 2px，字号 11/700 白；弹入 pop 300ms |
| 金圈诞生 | r=10px 起扩散，stroke 3px halo 0.85，900ms 依次延迟 90ms |
| 剪断反馈 | 断点闪 260ms（浅灰 r=10 扩散） |

## 四、生成规律

1. **新结诞生位置**：来源结（V_b 质心）右下方偏移 (+160, +120)；诞生动画：滑出+淡入 300ms
2. **初始布局**：按 chain 分组，组内纵列排布（列距 420px、行距 220px），组间 48px 间隔；同 chain 链式直线相连
3. **尺寸随内容**：折叠态宽度=min(240, max(140, 标题宽+40))；展开态固定 240px，块内容超高滚动
4. **层级涌现**（预留）：结→链（绳串）→簇（P4 聚合）→云图（语义缩放远观）

## 附：FlowGram 引擎红线（瞬移四连坑，实测血泪）

1. **节点级禁止 transform**——FlowGram 用 transform 定位节点，任何 CSS/动画的 transform（scale/translateY）都会覆盖引擎定位 → 卡片瞬移。节点动效只用 box-shadow/opacity/border。
2. **禁止改引擎 size 来响应形态变化**——size 变化会让引擎重新锚定位置（卡片跳到鼠标右下角）。展开/收起走绝对浮层（引擎尺寸恒定），不做引擎 size 同步。
3. **bounds 不可当锚点**——引擎 bounds 可能与视觉尺寸不一致（历史快照残留）。拖动/定位一律用纯 position（左上角）+ 相对位移。
4. **屏幕坐标用 DOM getBoundingClientRect**——toFixedPos 语义不可靠（容器偏移丢失）。SVG 浮层（预览/徽章/金圈）全部屏幕坐标直出（clientX/Y + DOM rect）。
