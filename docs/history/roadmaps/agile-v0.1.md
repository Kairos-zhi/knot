# 结 · 敏捷交付路线图 v0.1

> 2026-08-29 凌晨 · 原则：先验证后代码，每模块自带验证点，无验证不交付

## 模块总览（按重要度排序）

| 序 | 模块 | 交付物 | 验证点 | 周期 | 依赖 |
|----|------|--------|--------|------|------|
| M1 | 结纸面规则包 | 一页规则 + 实验记录模板 | 真实对谈走规则：分支数/提权数/省下的重复沟通 | 半天 | 无 |
| M2 | token 对比实验 | 线性 vs 绳结 token 账单对比图 | 省 token 量化证据（商业锚点素材） | 半天 | 无 |
| M3 | 外部验证 | 3 个外部创意者访谈 + 结论 | F1 解除：非我们的人用不用 | 一周 | 无 |
| M4 | 结·最小原型 | 开源轮子 + 3 结型 + 决策史时间轴 | 自己用原型做完一件真实的事 | 1-2 周 | M1 通过 |
| M5 | 灵感区 | agent 主动投卡 + 三属性动态 | 噪音边界：垃圾卡率、打扰感 | 后置 | M4 |
| M6 | 模板库 | 对谈整理链模板 v0.1 | 套模板 vs 空白起手时间差 | 后置 | M4 |
| M7 | 招商引流层 | MCP+A2A 接入规范 + 首插件接入 | 接轮子效率 | 后置 | N1 定案 |
| M8 | ADT 底座打通 | 治理流程→骨架功能清单（脱盔甲） | ADT 场景实跑 | 后置 | M4 |

## 本周快线（零代码三并行）

- M1 半天：纸面规则包（之与杜下一场对谈即实验）
- M2 半天：token 对比（同任务线性 vs 绳结模拟）
- M3 一周：3 个外部创意者（给痛点不给哲学）

## 纪律

1. M4 开工条件 = M1 验证通过（规则真的让对谈更快更发散）
2. M5-M8 全部后置，不做任何"先做出来再说"
3. v0.8 纲领 = M1/M2/M3 的实验结果，不是新功能
4. 产能（N4）：M1-M3 零代码可全员并行；M4 需确定"谁写代码×投入多少"，本周内拍板
