## 变换与没有公开的部分

1. 原始私人会议、聊天流水、个人哲学全集、内部活动日志及完整混合内容包不整包公开。
2. 所有迁入正文按现行入口加历史状态说明；本机绝对路径与内网文档链接转为仓库链接或明确的未归档来源文字。
3. 不上传原研究中的内部参考图片、游戏截图或原始素材；文字保留来源与图示说明。
4. 历史 roadmap 的内部采集运行明细省略，保留来源接入的产品要求与未完成边界。
5. 原候选的“本轮未测”等不重写为当时通过；现行状态页登记之后的实现、接受与合并。
6. 原文数字、论证与来源质量保持历史属性，本轮不担保其中每一条外部事实今天仍成立。
