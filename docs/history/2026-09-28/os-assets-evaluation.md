# knot 评估 · OS 对标 × 节点资产化 与交互逻辑推演

> 2026-09-28 · 依据：Apple 全生态对标定调（原话见 `knot定调_iPadOS对标_20260928.md`）
> 性质：**评估 + 推演**（分层声明——事实 = 之定调原话；推论 = 小禾，待之确认）

## 一、评估：OS 对标 × 节点资产化——逻辑为什么成立

**1. 它给"节点"升级了身份系统。**
画布范式里，节点 = "图上的一个点"——抽象、同质、没有自己的家。**窗口 = app 之后，节点获得系统级身份**：名字、图标、状态、独立生命周期。这才是"资产"的字面意思——**能在系统里被独立管理的东西，才叫资产**。

**2. 它解开了画布范式的死结：摆位的负担。**
画布让人**当管理员**（手动摆放、维护布局）；OS 让人**当主人**——窗口自动有位置、文件夹自动有归属、资源库自动有归类。**人只管关系（连 / 组 / 命名），不管摆哪。**

**3. 三个空域正好覆盖三种组织维度，互不打架。**
- 台前调度 = **时间维度**（正在进行的）
- 文件夹 = **结构维度**（按项目收的）
- 资源库 = **语义维度**（相似相近自动聚的）
——同一个资产可以在三个维度上被找到，且各自不重复劳动。

**4. 时机判断（为什么现在没人做成这样）。**
现有 harness 都在拼"接入模型能力"，形态全困在聊天侧栏/面板——因为它们的服务对象是**一个任务**。OS 范式是**多个 agent = 多个 app** 的唯一自然解：**谁会把 10 个 agent 塞进一个聊天侧栏？** knot 服务的是"一个人全部的工作"，所以形态必须是系统级。

**5. 风险清单（要设计的部分，别回避）：**
- **a) 窗口的生命周期**：窗口=app 若只增不减 → "app 爆炸"。需要：干完的现场**可归档**（收进文件夹 = 沉睡；资源库 = 索引）。铁律：**关闭窗口 ≠ 删除资产**。
  - **之的指认（2026-09-28）**：**Jev（受限决策器）的任务 = 快速把窗口转化为图标 / 卡片**——折叠 / 归档的决策交给 Jev（低风险、高频、要求快——受限决策器的理想用例；此前工程结论：P0 不接、P1 试点）。
  - **窗口三态（整理）**：**展开 = 工作**（台前调度，全交互）｜**卡片 = 挂着**（最小化仍在桌上，一眼可认）｜**图标 = 归档**（进文件夹 / 资源库，作为资产沉睡，可再打开）——Jev 决定何时与如何切换。
  - **与 codex《Jev 评估》的关系**（内容包 2026-09-28 节）：该评估定了底座判断（"P0 不接；P1 窄场景 sidecar 试点"）并列出四个适验场景，其中第 4 条「**桌面交互候选选择**：从已发现的窗口或有限动作中选择目标」——**"窗口→图标/卡片"即该条的具体化**：候选动作 = 折叠 / 归档（限制在有限动作集内），宿主仍负责执行、权限与结果验证。
- **b) 资源库的可编辑性**：iOS 资源库是只读自动归类；knot 的语义空间**要不要连线/打结**？若要 → **资源库 = 浏览层，画板 = 编辑层**（一套数据两个面，与画板定位推测对齐）。
- **c) 绳/结的作用域分层**：窗口**间** = OS 关系（切换 / 归档 / 拖动）；窗口**内** = 节点关系（棍 / 绳 / 剪）。两层别混，交互语言各归各位。

## 二、交互逻辑（按此逻辑推演）

### 三层结构

| 层 | 干什么 | 交互手法 | 对标 / 属性 |
|---|---|---|---|
| **系统层** | 管东西（找 / 开 / 切 / 归档） | 打开 · 切换 · 拖放 · 搜索——**不学就会** | iPadOS / macOS 惯性（零学习成本） |
| **工作层** | 干活（现场内） | **棍 / 绳 / 剪**——拿起 · 连接 · 拆开 | knot 独有手感（核心交互） |
| **语义层** | 重组（跨项目） | 资源库浏览 → 画板编辑（连线 / 打结） | 浏览 + 自由重组（低频高价值） |

**一句话：用 OS 的惯性管东西，用绳结的手感干活，用语义网重组资产。**

### 由 OS 化推出的五条交互原则

1. **操作对象永远是"东西"，不是"模式"**——直接操作（像拖一个文件），不切模式、不进菜单。
2. **勾选 = 上下文：在 OS 里的形态 = "手里拿着的东西"**——你选中的窗口 / 卡片，就是干活时带上的上下文（已有定案的自然延伸）。
3. **状态常驻但安静**——红绿灯 / 工作岛 = 窗口的角标与状态行：一直在、不弹、不打断。
4. **AI 主动 = 系统行为**——它的"来找你"（递灵感 / 建议整理 / 提醒）发生在**系统层**（工作岛 / 资源库 / 文件夹），**不是聊天框里发消息**。
5. **时间的原则**——时间轴留在**窗口内**（线性工作流的第四维）；系统层的时间表达 = 资源库的「最近」。
