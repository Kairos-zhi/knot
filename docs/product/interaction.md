# 交互约定

更新：2026-10-18。本页是目标行为约定；已实现范围以[开发状态](../development/status.md)为准，当前代码字段见[状态模型](../architecture/state-and-persistence.md)。

## 现场与呈现实例

一个现场承载正在处理的事及其连续性。一个或多个呈现实例引用它。不同现场之间隔离供给、草稿与 Agent 选择；同一现场的窗口、卡片和图标共享状态。

工作站内部桌面与后续外部浮窗可以同时存在。移出、收回或展开只改变呈现；完整编辑回到同一个现场，不能变成内容分叉。

## 动作与结果

| 人的动作 | 应发生什么 | 不应隐含发生什么 |
|---|---|---|
| 搜索、预览、点开材料 | 展示内容与来源 | 自动加入供给、切换 HUD 工作目标 |
| 拖到桌面或文件夹 | 建立节点或组织关系 | 自动授权模型读取全部内容 |
| 放入明确供给区／显式勾选 | 加入指定现场供给 | 改变其他现场的供给 |
| 从当前供给移除／剪断对应供给线 | 后续输入排除此材料，原件与历史保留 | 删除原材料或其他现场引用 |
| 窗口切成卡片／图标 | 同一对象紧凑显示 | 自动归档、停止或删除 |
| 关闭一个呈现 | 关闭该实例 | 取消已托管运行 |
| 明确停止运行 | 请求取消，显示确认的结果 | 用关闭动画假装已经取消 |
| 明确归档／删除 | 执行对应生命期操作 | 与最小化、断开供给混为一谈 |

普通关系、当前供给、历史 provenance 和可运行路径有不同业务语义。关系视图的线若用于剪供给，应操作同一供给规则；不能根据视觉邻近推断授权。

## 输入与多轮连续性

HUD 显示目标现场、Agent、草稿和实际选定材料。切换窗口保留各自状态。产品级 Focus 与鼠标选中的节点分开；预览其他材料不改变发送目标。

发送时固定本轮输入证据。后续移除影响下一次请求；已经外发的内容无法撤回。选入旧结果只授权所选内容，不递归加载其全部父输入；如果旧结果自身包含原材料文字，该文字属于被选内容。

旧会话、摘要与工具读取不能暗中补回已移除材料。不规定每次发送都新建 Provider Session；只有适配器不能安全表达新的输入边界时，才在该变化边界重建受控上下文，保持用户工作连续性。

当前本地编译／请求测试只证明数据边界，尚未证明模型历史或工具沙箱行为。

## 工作岛与后台活动

活动应来自可追溯 Run／事件。未开始不能显示 running；完成、失败、取消、待授权、失联分开。没有真实百分比就不伪造进度；token 预估和实际 usage 分开。

点击活动回原现场；后台任务仍归原现场。页面或外部组件关闭后，产品目标是已托管任务仍可回收；这是后续运行验收要求，不能由本地“未调用取消端口”的测试推成已经实现。

## 一次连续工作验收

| 轮次 | 用户操作 | 预期供给 |
|---|---|---|
| 初始 | 预览 K-01、N1，不明确引入 | 空 |
| R1 | 选 I1/I2/I3，分别交给 Codex、Hermes | I1、I2、I3 |
| R2 | 增加 I4，Codex 继续 | I1、I2、I3、I4 |
| R3 | 移除 I2，选入 R1 的 K-02，Hermes 继续 | I1、I3、I4、K-02 |

每个运行有独立身份，结果保留来源；新结果默认不再加入供给。检查 I2 是否泄漏时，使用未包含在 K-02 中的专属标记，避免误判。完整证据要求见[验收](../development/acceptance.md)。

## 可访问性与自动行为

手势提供点击／键盘等价动作；焦点可见，减少动态效果有替代反馈；内容与状态不只靠颜色表达。自动整理尊重人工固定和排除；候选选择失效时保持可解释的确定性行为。具体系统级快捷键、浮窗尺寸和动效参数在宿主验证后冻结。
