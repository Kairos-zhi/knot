# 产品总览

更新：2026-10-18。来源：9 月产品总纲、工作台方案及后续明确的产品澄清；原候选见[历史索引](../history/README.md)。

## 是什么，为谁存在

Knot 给人和 Agent 一个共同的工作环境。结是可继续使用的资产单元，绳表达资产间的连接或供给关系，块保留有序内容及来源。资产可以承载材料、会话片段、想法、决策和结果。

首批面向已经使用 AI 进行研究、创作、方案与开发的人。需要验证的价值是：能否持续推进真实工作，能否找回材料和结果，能否用已有产物产生下一步。尚无产品级证据支持固定的省时、token 节省或创造力提升比例。

## 工作站、桌面与外部呈现

工作站承担完整编辑、组织、协作与检查。内部桌面是摆放和取用会话、文件夹、图标与卡片的空间。系统桌面上的外部浮窗和组件是后续承载方式。

三个层次可以同时存在。同一对象换一种呈现，不复制资产，不新建无关对话，也不改变真实运行的生命期。用户可以让出屏幕，也可以全屏工作；焦点与占屏来自人的选择。

| 入口 | 职责 |
|---|---|
| 项目文件夹／图标 | 组织、识别与打开资产 |
| 工作窗口 | 处理一件事，保留意图、对话、供给和产物 |
| 卡片／图标形态 | 紧凑呈现同一现场，随时恢复 |
| HUD | 明确当前输入目标、Agent 和供给材料 |
| 工作岛 | 真实活动的摘要与返回入口 |
| 角落组件 | 轻功能、固定现场与近期结果 |
| 关系视图 | 按需查看连接、来源与重组路径 |
| 资源唤出入口 | 查找已授权的资产、现场与来源 |

## 一次完整的目标体验

1. 打开项目，找到已有材料与产物。
2. 开始或恢复一个工作现场，选择此次供给。
3. 输入需求，选择 Agent 并发送；运行归属清楚。
4. 结果带来源成为资产，继续加工时显式选择。
5. 修改供给、切换 Agent，保持工作连续性。
6. 收起、切走、回来，仍能恢复原现场。

查看、展开和搜索命中不自动授权给 Agent。移除材料只改变该现场后续供给，不删除材料，不修改过去来源，也不能撤回已经发出的内容。实际模型会话和工具的边界需要真实运行验收。

## 创造性与主动协作

产物可以继续生长、比较、组合和引用。已授权范围内的成结、整理与维护可自动发生；人工断开、固定和隔离具有覆盖权。低风险整理不必变成每步审批，但它也不能扩大输入或来源权限。

首轮先验证一个真实工作的连续闭环。来源连接依次从已有 Agent 项目／任务开始，再评估授权信息流与可靠搜索，之后扩展到目录／NAS。复杂关系编排、语义模型训练、市场和社区机制保持长线。

## 当前实现与下一步

已合入的是共用数据和操作基础，尚非上述完整体验。当前 Worksite 仅保存关联资产／对话、草稿、Agent 选择、供给与排除；完整 Project、产品级 Focus、Run 与来源连接仍需增量设计。具体见[状态模型](../architecture/state-and-persistence.md)。

开发顺序按[路线图](roadmap.md)与[近期计划](../development/plan.md)推进。方向、建议、已经实现与已验收分别登记，不把历史原型当成最新产品主壳。
