# 哲学与 AI 原生范式

来源：9 月总纲、既有 Agent 原生标准与人类可读性原则；本页整理产品相关部分，不收录私人对谈或个人哲学全文。

## 思考资产化

一段对话的价值不应只停在消息历史里。材料、想法、决策与结果需要稳定身份、来源和可再次引用的内容。结由有序块组成，可以追加、生长和重新组合；摘要是入口，不能替代可取回的原文。

“资产”不等于复制一份文件。不同工作现场可以引用同一材料，历史来源与当前供给分开，形成的结果也可以成为下一步的材料。

## 人和 Agent 共用环境

原生感知：状态有数据出口。原生调度：动作有可调用操作。开放接入：业务语义不依赖某个宿主私有 API。人的界面操作与 Agent 调用应共用同一内核。

“人2a2a”描述协作关系，不是新增一个专有传输协议。业务命令、外部 Agent 运输、工具协议和 UI 声明分层适配，不能用名称相似代替实际兼容。

## 活结与人的选择权

连接应当像活结：可以建立、断开、重选和重新组合，关系的来路仍然保留。结型表达路径、关联或待拆问题等语义，不直接表达权限；读、写和 Agent 使用由供给范围、目标操作、调用者身份与授权策略独立校验。选中、展开或看见关系，不自动授权。

## 自动织养，手动覆盖

Agent 可在授权范围内生成、归类和维护结构。用户能拖拽、固定、连接、断开和隔离；人工排除不能被普通预览、恢复或自动整理悄悄撤销。

这种主动性服务于创造和持续工作。它的质量需要观察噪音、打扰、用户是否采用以及能否解释来源，不能仅以自动动作数量衡量。

## AI 用得爽，人类看得懂

给人先呈现当前在做什么、发生什么、要决定什么、下一步能做什么；给执行层保留完整状态、来源、命令、证据和未覆盖项。工作岛和窗口提供渐进披露，不把治理表单压到用户每次操作上。

研发侧保留任务、回执、独立核验和溯源；它们支持可信交付，并不要求产品长成一套审计后台。

## 从个人到协作

个人持续产出可复用案例，协作经验反馈产品，产品支持下一次创造。社区与模板生态是长期方向；首轮以真实任务检验个人工作闭环，不预先承诺生态规模或商业结果。
