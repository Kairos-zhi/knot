UI：从已加载保存版本明确选择来源；候选证据全部默认未勾选；显示完整固定版本、每条锚点与导出目的。范围/任务ID可明确填写，另有显式生成本机标识按钮，不隐式代表平台ID。生成预览后展示完整JSON与摘要；人勾选“已核对完整预览，仅确认本机导出”才允许确认。任何输入、证据或来源变化都使旧确认失效；请求进行时禁用相关编辑，异步响应还须检查生成代次，防止旧响应恢复旧确认。

不自动prepare/export、不自动打开文件夹或浏览器下载。页面显示本机文件名，不回显绝对路径、凭据、被抑制正文；复制或截图进入其他程序的影响由操作者掌握。预览/导出丢响应后不自动重试；已知packet_id可明确再次确认同摘要，只有已验证本机包才报告成功。

## 启动与走查

使用已有隔离Python、后端和操作者选定的仓库外本地私有目录；KNOT_WORKBENCH_TOKEN在进程环境提供。根目录需先由操作者准备，网页不能选择任意文件系统路径。

```powershell
& $knotPython -B -m mvp.devtools.workbench --origin $knotOrigin --packet-root $knotPrivatePacketRoot
```

可额外提供--state-root启用已复核的探索保存；不提供state-root也能使用本卡已保存版本的预览/导出。未提供packet-root时不启用新的导出POST。打开命令返回的本机URL；本卡没有安装到当前桌面或自动打开浏览器。

从探索列表加载一个保存版本 → 使用已加载停点 → 明确填写或生成本机范围/项目/任务标识 → 主动填写进展摘要 → 逐项勾选允许导出的锚点（也可全部不选）→ 生成完整预览 → 核对JSON、项目/任务、固定版本与摘要 → 勾选本机导出确认 → 导出。页面只显示UUID文件名，实际目的地为启动时指定的私有目录；不上传、不自动下载或打开文件夹。

遇到不明结果时保留预览，核对后可再次明确确认同一包；只有完整已存内容验证一致才取回成功回执。修改字段或切换来源必须重新预览、重新确认。材料归属与平台绑定均不自动推断。
