# 09C4 新库默认 1.9

本候选只对独占新建的暂存库依次应用既有 1.7、1.8、1.9 迁移；所有连接关闭并检查 WAL 已 checkpoint、自包含后只读校验，再以 create-only 硬链接发布并复核身份。已有目标一律拒绝，不自动迁移。

最终目标同名 WAL、SHM 或 journal 已存在时拒绝创建并保留侧车；发布后若发现侧车，则仅在确认目标为本次创建对象时移除目标，保留外来侧车并报告失败。检查不承诺抵御任意特权并发篡改。

校验覆盖完整版本集合、探索表和触发器精确结构、来源一致性、数据库完整性及既有基础检查，并非全部基础 DDL 的完整认证。旧版本的显式升级、在用服务停止和唯一写入者仍需另行授权核查；本卡的技术验证不代表部署或产品接受。
