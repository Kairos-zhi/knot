# 09C1 探索关系核心

本卡提供私有探索快照的暂定关系和显式 1.8 格式屏障；不接传输、分岔、安装或真实业务迁移。1.7 历史保持原字节，迁移检查结构和完整历史后仅追加版本。旧程序的严格 1.7 检查拒绝 1.8；运行中的服务及其他 CLI 不因此自动安全。

`save_v2` 必须显式提交版本 2、完整有序引用、停点及关系列表，并沿用 owner、CAS 和 actor/request key。关系包含稳定 ID、有序端点、label、reason；端点必须是不同的 selected 材料。同一探索中相同关系 ID 的端点不可变化，解除需显式移除，恢复须沿用原端点。关系不表示事实确认或授权。旧保存不能覆盖任何已进入 v2 的探索；成功旧请求的原 key 可仅重放收据。跨版本复用 key 或改变请求冲突。

`load_v2` 可读取历史 v1（展示版本 1 与空关系）或 v2；读取时重核所有材料的 reader/hash，不可用端点隐藏关系 label 与 reason，任何引用不可用时隐藏停点。该投影不是可直接写回的保存请求。旧 load 对 v2 拒绝。存储快照字段闭合，重复键、无效版本和损坏格式拒绝。任何真实迁移或产品使用需要单独授权及对应验证。
