# GLOBAL-TIME-001｜同一个时间位置浏览项目与原话

2026-11-18，基线1f3deb3。承接用户反馈：时间轴应追踪新项目出现，项目导航和时间浏览连续，参考Apple系统组织而非仅装饰。程序化验证，不截图或模拟点击。

## 定义与写集

- ProjectList增加可选chronology：appearance_at非负整数毫秒，appearance_basis为registry_created/first_message/first_saved，registry_created和first_message必须带appearance_source现有材料ref，first_saved不带；observation_times为排序去重的真实受权原话毫秒数组（至多128），observation_count为受权原话数。旧无该字段列表仍可读。只基于可读当前材料、受权manifest；不可读来源不能泄露日期。登记时间来自保留的project-registration.json文档，version/source/project_id及created_at_ms准确匹配，不能从名字或导入时间猜创建。取登记时间与最早原话的较早者，两者皆无取最早可读实际留存，分别标注依据，不称业务真实诞生。原source/asset/manifest唯一权威不变。
- 全局时间轴始终可见，日期站点由所有可读项目的出现时间和原话时间组成，标明是有记录的日期、非均匀日历刻度。早在上、晚在下（用户明确要求）；拖动即更新同日新增项目及截至该日项目列表。进入项目/返回全局/切项目保持同一日期；最新按钮解除日期范围。未知时间单独说明，不伪造日期。
- 项目详情在同一截止日期读原话。拖到当前项目出现前，清楚说明并展示该日出现的其他项目入口；不能展示未来原话，也不能静默跳项目或改变编辑目标。编辑中的文字不因拖动清空；允许暂时禁用拖动并说明需结束编辑，而非丢输入。最新态保留现有整理修订、工作回顾及不确定保存恢复语义。
- 层次保持为稳定侧栏（所有项目、时间、项目列表）+内容，去掉“其他项目”折叠门槛。主标题/时间范围与选择一致，返回全局不是恢复最新的隐含动作。版本历史仍单独保留，不能冒充全局过去快照。登记日后的卡片出现不声称已恢复缺失正文。
- 主Agent写backend/project_repo.py、project_policy.py、contract/v1/schema.json、devtools/codex_capture.py与领域测试，及私有运行helper补留登记时间（同库备份后追加文档，不覆盖旧文档）。前端Maker仅workbench.html与相应DOM测试。独立Checker先核定义，再核联合实现Gate；Gate前不部署。禁止推送/合并/真实模型调用。

## 验证目标

两个不同出现日期项目，拖动前后可见集合和当天新增准确；跨视图日期不变；缺失chronology兼容；登记与原话依据分明；同名不合并，已确认关联仅沿既有映射；撤权材料不泄日期；同库追加后旧版本可读。保留已有编辑与保存恢复回归。

参考：Apple HIG Sidebars（稳定集合导航、清晰层次）；Sliders（明确范围/刻度与即时反馈）。纵向时间顺序遵从用户从上到下浏览的明确要求；不宣称是系统原生控件。
