# PROJECT-CONTINUATION-001｜从项目交接到下一窗口

对应原 Roadmap v1.0 Week 3 Day 16、18、21。开发入口为当前可运行的项目工作台。在同一个项目中选择原文，核对已保存的回顾，预览人可以接着用的 Markdown。

- 沿用项目版本、材料权限和原文出处。项目回顾按原有规则重新核源，并用「概括待核」标注。
- 预览同时显示完成情况、阻塞、下一步、待核问题和用户选中的材料。长材料明确标记为摘录。
- 复制或下载前确认当前项目版本、预览和材料仍匹配。新读取失败时保留选择，撤回过时预览。
- 使用公开合成项目验证从发现入口、选择材料、预览到产生可读 Markdown。入口使用现有工作台，原 Roadmap 的核心续接包、形成路径和桌面安装分别验收。
